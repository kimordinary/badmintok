# 2026-07-15 앱 반영 요청 — 정원 성별 토글 · 쪽지

> 이번 배포에서 **새로 추가/변경된 것만** 정리. 앱에서 이 두 가지를 반영해 주세요.
> 서버는 프로덕션 반영 완료. Base URL `/api/bands/`, `/api/notifications/`. 인증 JWT.

---

## 1. 번개 정원 — 성별 토글을 급수와 **독립**시킴

### 무엇이 바뀌나
기존엔 "성별로 나눠 받기"가 "급수별 정원"의 하위 옵션이었음. → **두 토글을 독립**시켜, 급수 없이 **성별로만** 정원을 받을 수 있게 됨.

두 bool 값이 직교(독립) → 4모드:

| use_level_quota | quota_by_gender | 모드 | 정원 필드 |
|:-:|:-:|---|---|
| false | false | 제한 없음 | `max_participants` |
| true | false | 급수별 | `level_quota {lv:{total}}` |
| **false** | **true** | **성별 전용 (신규)** | **`gender_quota {male,female}`** |
| true | true | 급수+성별 | `level_quota {lv:{male,female}}` |

### 신규 필드
- `gender_quota` (JSON): `{"male":10,"female":10}` — **키 없는 성별은 모집 안 함** (예: `{"male":10}` = 남자만)

### 생성/수정 화면 (UI)
- **[급수별 정원 받기]** 토글과 **[성별로 나눠 받기]** 토글을 **각각 독립**으로.
- 급수 OFF + 성별 ON → **남/여 2줄 입력** (한 성별만 받으려면 다른 쪽 0/빈칸).
- 요청 body 예:
  ```json
  { "use_level_quota": false, "quota_by_gender": true, "gender_quota": { "male": 10, "female": 10 } }
  ```
- 검증: `quota_by_gender=true && use_level_quota=false`인데 `gender_quota` 비면 → `400 "성별 정원을 입력하세요."`

### 신청 (apply) — 성별 전용 모드
`POST /api/bands/<bid>/schedules/<sid>/apply/`
- 신청자 **성별 칸** 기준으로 마감 판정. 꽉 차면 `waiting`(대기).
- 신청자 성별 없음 → `400 "성별 정보가 없어요. 프로필 성별을 확인하세요."`
- 모집 안 하는 성별 → `400 "이 모임에서 모집하지 않는 성별이에요."`

### 상세 (detail) 응답 추가 필드
`GET /api/bands/<bid>/schedules/<sid>/`
```json
{
  "quota_by_gender": true,
  "gender_quota": { "male": 10, "female": 10 },
  "gender_status": {
    "male_approved": 4, "male_quota": 10,
    "female_approved": 6, "female_quota": 10
  },
  "quota_status": null,
  "is_full": false
}
```
- 성별 전용이면 `gender_status` 채움 / `quota_status=null`.
- 급수 모드면 반대 (`quota_status` 채움 / `gender_status=null`).
- 표시 예: `남 4/10 · 여 6/10`.

> 전체 정원 스펙(4모드 상세)은 [lightning-matchmaking/quota-spec.md](./lightning-matchmaking/quota-spec.md).

## 2. 쪽지 — 보낸 쪽지 조회 추가

기존엔 **받은 쪽지**만 볼 수 있었음. → **보낸 쪽지** 조회 API 추가. (마이페이지 "내 활동")

### 받은 쪽지 (기존)
- `GET /api/notifications/?type=schedule_notice`

### 보낸 쪽지 (신규)
- `GET /api/notifications/sent/?page=&page_size=`
- 내가 발송한 일정 안내 목록. **동시 발송분은 하나로 묶음**(수신자 N명).
- 응답:
  ```json
  {
    "count": 12, "total_pages": 1, "current_page": 1, "next": null, "previous": null,
    "results": [
      {
        "message": "자리 났어요",
        "created_at": "2026-07-15T10:00:00",
        "band_id": 9, "band_name": "…",
        "schedule_id": 6, "schedule_title": "토요 번개",
        "recipient_count": 3,
        "recipients": [ { "id": 12, "name": "홍길동" } ]
      }
    ]
  }
  ```
- UI: 마이페이지 "내 활동"에 **[보낸 쪽지]** 항목. 각 카드에 `받는사람 홍길동 외 2명` + 메시지 + 일정.

> 쪽지 발송/대기 전체 스펙은 [lightning-matchmaking/waitlist-spec.md](./lightning-matchmaking/waitlist-spec.md) §3.4.
